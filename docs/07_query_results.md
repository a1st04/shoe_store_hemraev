## Выводы

- **INNER JOIN** отсекает строки без совпадения в обеих таблицах; **LEFT JOIN** сохраняет левую таблицу полностью (NULL в правой).
- **COUNT / SUM / AVG / MIN / MAX** — базовые агрегаты: работают и по всей таблице, и по группам.
- **GROUP BY** сворачивает строки в группы; в SELECT можно выводить только группировочные поля + агрегаты.
- **HAVING** фильтрует уже сгруппированные данные (в отличие от WHERE, который работает до группировки).
- Пустые результаты в запросах 14, 15, 16, 18 — **не ошибка**, а следствие того, что в тестовом наборе просто нет подходящих записей.
