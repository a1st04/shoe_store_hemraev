## Выводы

- **Подзапрос в WHERE** возвращает одно значение (скаляр) для сравнения.
- **Подзапрос в FROM** ведёт себя как временная таблица — к нему применимы WHERE/ORDER BY снаружи.
- **IN** удобен для коротких списков; **EXISTS** эффективнее на больших данных (проверяет наличие).
- **RANK** при равных значениях пропускает номера (1,2,2,4); **ROW_NUMBER** — нет (1,2,3,4).
- **PARTITION BY** делит строки на группы, но не схлопывает, в отличие от GROUP BY.
- **SUM(...) OVER (ORDER BY ...)** даёт накопительную сумму без потери строк.
- **LAG** возвращает значение из предыдущей строки — удобно для расчёта интервалов между событиями.
